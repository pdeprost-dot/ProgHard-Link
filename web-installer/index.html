ProgHard Link Web Installer

Flash ProgHard Link Base directly from your browser.

Supported devices: ESP8266, ESP32, ESP32-C3 and ESP32-C6.

  1. Connect the device to a USB port using a data cable.
  2. Click “Install ProgHard Link”.
  3. Select its serial port. The compatible firmware is selected automatically.
Web Serial is unavailable. Use Chrome or Edge on a computer. Open this page over HTTPS or from localhost to allow Web Serial.

After installation

  1. Connect to the setup Wi-Fi named ESPway-XXXXXX.
  2. Open http://192.168.4.1/ and configure your Wi-Fi plus the ProgHard Link instance.
  3. After the device joins your LAN, open its local page and choose Register this device in ProgHard Link.
  4. Sign in and confirm. The device appears in My devices; no Device ID or machine token needs to be copied.

Registration creates the secure machine identity behind the scenes.

Base firmware 0.2.3 · Arduino library 0.4.9 · Use Chrome or another browser with Web Serial support.
